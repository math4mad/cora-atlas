# 知乎回答版（去答 2011 年那一类问题："如果想学线性代数，应该学什么？"）

十五年前，我就是这个问题在知乎得到的一个回答：MIT OpenCourseWare，18.06，Gilbert Strang。

对很多人那只是一个普通的建议。对我来说，那是我人生里第一个 token——它没有告诉我任何信息，它点亮了我概念空间里一大片当时还不存在的区域。

后来发生的事有点长，一句话版本是：我把那门课里最老的三件家具——四个基本子空间、秩一分解、一面国旗——搬进了大模型时代，攒出一个理论，昨天刚把它寄给教授本人的信箱：

**一个 token 不是信息的载体，它是对一片概念空间的探针。**

特征脸是它，JPEG 是它，突触记忆是它，大模型的词表也是它。数与形同源，懂与到过同义。

如果你现在想学线性代数——学它。还是那句话。
