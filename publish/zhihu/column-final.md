# 一个 token 的自白：从 18.06 到概念空间导航

> 摘要（知乎专栏简介栏用）：十五年前我在知乎问"学线性代数该学什么"，回答是 MIT 18.06。十五年后我把那门课里最老的三件家具，写成了寄给 Gilbert Strang 的一封信和一篇论文。

**序**
十五年前我在知乎问：现在想学线性代数，学什么？回答：MIT OpenCourseWare，18.06，Gilbert Strang。
十五年后，我把答案寄回了源头——公开信与论文 v2 都在 math4mad.github.io/cora-atlas ，信已于昨日送达教授在 MIT 的信箱。

**一、探针，不是载体**
我问侄女"11 是什么"：一个数字。问我大哥：姚明。一位资深火箭蜜：从奥拉朱旺到哈登，一条时间线。
token 从未变过，变的是你心里那张图。
所以 prompt 工程的第一性原理不是"写清楚"，是**打准点**。

**二、四把家具，一张图纸**
Strang 给我上了三课，顺序很要紧：
1. **四个基本子空间**——列空间、零空间、行空间、左零空间：两对正交，一秩调和，线性代数一整页画完；
2. **秩一矩阵**——万物皆秩一之和；
3. **一面国旗**——色条即秩一分量的叠加。
后来我在人脸（特征脸）、JPEG（DCT）、突触（Hebbian 学习）里重逢同一结构，才知道它叫**基系数表征**——四个领域，只是四座坐标系。

**三、时间无维，序号为骨**
v2 的宣言：**散点图记录的是系统内部属性的变化，这个变化是自足的。时间是变化的度量，不是变化的前提；序号才是系统的骨架，时间只是序号的一个可选注释。**
——冷笑话为证：x 轴上诸点的妈是 numpy。matplotlib 的 `plot(y)` 里，x = np.arange(len(y))。系统只产 y，x 是绘图库白送的。这是全论文最冷、也最准的一记脚注。

**四、彩蛋**
本文藏着两个 token：`11` 与 `18.06`。
哪个点亮了你？亮了多久？又亮到第几层 rung——是数字，是那门课，还是四个子空间齐现、SVD 之影立在身后？
你的眨眼就是问卷。**Atlas 不要求相信，只要求到过。**
