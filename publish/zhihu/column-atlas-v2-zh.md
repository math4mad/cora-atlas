# 知乎专栏版《一个 token 的自白：从 18.06 到概念空间导航》

**序**
十五年前我在知乎问：现在想学线性代数，学什么？回答：MIT 18.06。
十五年后我写了一篇论文，把它寄回了那个回答的源头——作者 Gilbert Strang。信与论文都挂在 math4mad.github.io/cora-atlas。

**一、探针，不是载体**
我问侄女"11 是什么"：一个数字。问我大哥：姚明。一个资深火蜜：奥拉朱旺到哈登，一条时间线。
token 从未变过。变的是你心里那张图。——所以 prompt 工程的第一性原理不是"写清楚"，是"打准点"。

**二、四把家具，一张图纸**
Strang 给我上了三课，顺序很要紧：
1. 四个基本子空间——列空间、零空间、行空间、左零空间：两对正交，一秩调和，线性代数一整页画完；
2. 秩一矩阵：万物皆秩一之和；
3. 一面国旗：色条=秩一分量的叠加。
后来我在人脸（特征脸）、JPEG（DCT）、突触（Hebbian）里重逢同一结构，才懂这叫基系数表征——四域只是四座坐标系。

**三、时间不维，序号为骨**
v2 的宣言：散点图记录的是系统内部属性的变化，这变化是自足的。时间是变化的度量，不是变化的前提；序号才是骨架，时间只是序号的一个可选注释。
——x 轴的妈是 numpy。这是冷笑话，也是本论文最冷的一记脚注。

**四、彩蛋（专栏版也只此一句）**
本文里有两个 token：`11` 与 `18.06`。
哪个点亮了你？亮了多久？——你的眨眼就是问卷。Atlas 不要求相信，只要求到过。
