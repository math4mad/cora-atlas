# 备忘 · arXiv endorsement code 之效期与用法（2026-10-06）

## 一 · 官方事实（arXiv 帮助逐词核讫）
- `info.arxiv.org/help/endorsement.html` **未给 endorsement code 写任何到期日**（expire/valid/days 皆无）。
- **一码可给多位 prospective endorsers**：原文「an endorsement request email — a link you can provide to
  prospective endorsers」＋「a **six-character alphanumeric endorsement code**」。
- 担保人在 **https://arxiv.org/auth/endorse** 输码投「是/否」；**一类别 ≥1 票正**即解锁。
- 码是「**开始一次 submission**」时 arXiv 发来的 endorsement request email 里的。
- arXiv 保留在违其政策时**撤销**之权。
