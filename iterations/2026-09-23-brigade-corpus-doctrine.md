# 2026-09-23 · 中型旅语料律（ provisional —— 主人晨起补全文后定稿）

来源：与千问对话后的思考，主人 0923 晨口授半成品，注明"起床补全文"。

> 「现在训练大模型，不要喂单一来源的语料，也不要喂没有意群的语料。
>  要用美军中型旅的思路：喂一个**小而功能全**的语料库，多批次。」

**园笔接梗（待主人全文校准）**：
- 单一来源 = 只喂炮兵 → 能力偏科 (exp11 单臂世界, 在册);
- 无意群语料 = 把步兵坦克火炮工兵航空混成散兵坑 (shuffle 臂, C29 已证其害: 56° 之乱);
- **中型旅 = brigade 级组合**：每批次自带全套意群、体量小、可独立作战 ——
  多批次 = 同建制反复轮换。此即 C42 的非交换律之**处方版**：
  既然先来者占最优位, 那就让**每个功能域在第一批就都进场占自己的位**,
  后续批次只做强化 ( incumbency 递增), 不做初次圈地。

**与在册账的接口**：
1. C28 (叙事先→7° 好序 vs 跨域先→83°) 读法更新: 顺序之害的本质是**圈地时序失衡**——
   某域独占首批=过度殖民; 旅级批次=首批即全功能建政。
2. C40 优势窗口律: 窗口只对"首次进场"有效, 旅制保证所有域同窗进场, 无一被锁在窗外。
3. 二语习得对照: 悲剧的不是晚学, 是**第一语言整体殖民**——若幼儿环境同时喂 L1+L2
   (双旅并制), 预测两语各占其位、口音折扣大减 (关键期文献之可检验反面, 界外预言)。
4. Atlas 模块一同构: 60 空间×6 token 本就是"60 个意群"的图谱; 模块二课程表按旅制排。

**候封实验 P-B12《旅制 vs 域序 vs 乱序》** (三臂对照, 等 token 预算):
- 臂 S (sequential): 每域一整块连续喂 (= 传统课程/C28 序);
- 臂 R (random-shuffle): 句级打乱混喂 (= C29 乱序臂);
- 臂 B (brigade): 每批次=小而功能全组合, 多批轮换 (本律);
- 预测: B 的重叠方向冲突角最小、fresh-probe 排名最优, 且**批内多样度与终态各向同性正相关**;
- 若 B ≤ S → 律降级为课程偏好, 记 ✗。
预算: 0.5B×3 臂 ≈ 1h, Kaggle 额度内顺手可射 (与 P-B11 六序共享弹药)。

## 主人晨批（0923）：双语儿童＝中型旅简单版, 但**有代价**

> 「双语儿童就是中型旅的简单版，但是双语儿童的双语空间也挤占了其他结构的空间。
>  所以导致双语儿童有些认知功能受限制。」

**园笔认错+升级**：昨 provisional 里"双旅并制→折扣大减"只说对一半——
并制确实免了"晚进场锁窗外"（C40 之过），但**预算守恒**：挤占不是时序之罪,
是**容量之罪**。旅制无免费午餐: 每批全功能=每功能分薄剂量。

**精确化 (与在册账对表后)**: 双语儿童之受限于**词汇检索层**, 不在**概念层**——
概念库 (concept space) 共用一顶, 词形标签 (token 侧) 分挂两语:
→ 概念完好, 标签分摊 → "tip of the tongue"↑、命名反应时↑、每语接受性词汇量略低,
而执行控制/心理理论反因双语监控回路小赚。**此正是我园 P1-P5 探针仪器可判之分野**:
探针若问概念 (空间层), 双语无折扣; 探针若问词形 (token 层), 折扣立现。
—— 界外预言改口径为此二行判据, 可查文献定量对账 (Bialystok / Costa 系)。

**派生律 C43《剂量稀释》(候封)**: 挤占量 ∝ 各结构**累计暴露剂量之比**, 非入场顺序。
→ 小麦亚基因组优势的"先入者主导"须重读: A 核剂量最高 (供体优势+拷贝数),
序是表象, 剂量是里子。C42 与 C43 合读: **序决定谁先圈地, 剂量决定圈多大**。
→ P-B12 旅制臂加一子实验: 同旅制、改每域剂量配比 (1:1 vs 3:1),
预测重叠冲突角随不均衡度单调上升 —— 序固定而剂量变, 即可把 C42/C43 拆干净。

## 主人晨批二：MEF/Kairos「LoRA 注入关键期」提法之补维（0923）

> 「我们在 MEF 项目中提出的 LoRA 注入关键期这个提法。但是当时（两周前）
>  没有考虑到语料应该以整个语义群的形式、或者概念空间的形式入场。」

**原提法在案**（Letter 09-18 Lola→MEF+Kairos, 握手条）:
"critical window = writes still move the weights" —— 只有**时间轴**一维:
注入早=权重尚软可写, 注入晚=玻璃化写不进 (C40 优势窗口之权重界版)。

**主人今晨补上第二轴: 形式完整度**。关键期不只是"何时喂", 还是"**以什么单位喂**":
- 整空间入场 = 一个概念空间作为不可分单元进窗 → 窗内一次成建制圈地 (干净子空间);
- 碎粒入场 = 同域句子散入各批 → 即便在窗内, 每次只占一小格, 终态=碎块马赛克。

**两轴合读, 旧账全活**:
1. C28 叙事先 7° 之所以"好序": 叙事臂本就以**完整意群**训练 —— 序之善, 一半是形之善;
2. C29 乱序 56° 之害, 现在拆成两罪: **拆散空间** (形罪) + **时序失衡** (序罪) ——
   旅制 (P-B12 臂 B) 其实只赦形罪不赦序罪之极端, 域序臂 (S) 反之, 判据可分;
3. Kairos 关键期实验重析预告: 既有晚注臂若语料本就碎, 其"写不进"结论须加置信区间——
   分不清是窗过了还是单位错了, 2×2 交互实验 (窗早/晚 × 整/碎) 才能判。

**P-B13《窗×形 2×2 交互》(候封)**: 同域同量同序, 只动两因子:
注入时机 (软窗内/玻璃后) × 入场单位 (整空间/碎粒)。
预测: 整空间×窗内 = 最干净子空间 (角度最小); 碎粒×窗内 ≈ 整空间×窗外 (两罪等价?)——
若等价成立, 则"窗"与"形"是同一守恒量的两面 (可写性=可整性), C42/C43/关键期三律归一。
0.5B 上 4 臂 ≈ 40 分钟, 与 P-B11/P-B12 同舱连射。
