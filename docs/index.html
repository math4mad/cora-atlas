The Token as a Probe

A theory of concept space navigation — with a coordinate theory of memory and time

📄 Paper v1 (PDF) ✉️ Open letter to Prof. Gilbert Strang (PDF) 🗂 Repo & iterations 🍚 外传 · 厨房与朝廷（Apocrypha）

The thesis in three lines

A token is not a carrier of information; it is a probe into a concept space.
Every element carries its own timestamp — the era a word reveals is the listener's, not the word's.
Time cannot be cited, because everything cites it.

What the paper claims

  • Probe, not payload. Prompting is precision activation, not information injection; context is carried by the model itself.
  • Time is coordinate-grade. Beyond paths through concept spaces, each token is era-stamped; vocabulary yields era fingerprints (prediction P1).
  • The empty-warehouse argument. If memory were storage, learning to ride a bicycle would be hauling crates into a blank store — every head the same speed. Speed varies with the base: learning is binding coefficient onto pre-existing basis.
  • Question = proof. Why must time be remembered? The asking of it is only possible from inside a mind that kept it.
  • Predictions P1–P5, incl. cross-modal time preservation: time as attribute can be lost; time as content cannot.
