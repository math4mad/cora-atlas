二 · 可视化军械库（V1–V10）

V1 圈地热力图（H1 精化） — 横 epoch × 纵七域，色 = k90 能量份额；新增右缘剖面：末 epoch 的份额条形（C43 的”冻结时刻”直读）。签名：红 = 阶梯，蓝 = 横纹。主判决图。

V2 干涉热力图序列（H2） — 每 epoch 一张 7×7 Gram 重叠阵；红方”霸权行”随 epoch 冻结（先入者行恒亮），蓝方近对角且亮度均匀衰减（各自收敛）。派生标量：行和最大值 V(t) → 见 M4。

V3 地籍 MDS / 测地地图 — 以逐 epoch 重叠阵为相异度做 MDS/embedding，七域各成一点，动画连播：红方后入点被先入点”引力”拖拽变形，蓝方七点等距绽放。此即 Atlas”概念空间地图”之生成过程实录 —— 论文图首选（一张动图讲完”结构是长出来的，不是训出来的”）。

V4 首次占领时刻图（order-of-invasion） — 每域画一条”能量份额首破阈值 τ”的时间竖线：红方竖线严格等距（块状开拔），蓝方近同步（旅级共发）。直接可视化”谁先圈地”。

V5 斩首矩阵（消融热力图） — 行 = 被投影剔除的空间，列 = 探针所属空间，色 = ΔNLL；理想模块化 = 对角阵。预测：蓝更接近对角（旅制各自成区），红出现上三角鬼影（后入域功能寄生在先入方向上 —— 挤占的病理切片）。

V6 缴械存活图 — merge 子代逐域”随红/随蓝”柱状（双列红蓝配色）；配合 epoch 轴 = 存活率曲线。A3 之量化：子代不随任何单方 = 真组合；系统性偏向某方 = 该方地籍硬。

V7 谱累积曲线 — 每域 ΔW 的 σ² 累积至 90% 所需秩 k90 随 epoch 演化：公平占领（蓝）⇒ 高有效秩；挤占（红）⇒ 低有效秩 —— C43 的谱学证据，也是 A1（低秩原子）的直接读数。

V8 地形剖面（loss landscape 探针） — 沿”红 checkpoint → 蓝 checkpoint”直线插值测 NLL（in-domain 与 OOD 各一条）：预测红蓝间有山脊（两 basin 两结构），同军相邻 epoch 间为缓坡 —— 结构 = 极小点的地形学正名，A4 之可视化。

V9 行为战损曲线（H3 精化） — 逐 epoch 冻结卷排名，双军 + 双 seed 四线；红方锯齿（学新忘旧 = 灾难性遗忘的行为面），蓝方平台爬升。与 V1 并排 = 结构-功能同屏，本案之”双子图”。

V10 探针迁徙图 — 抽 20 题，画每题 top5 激活空间随 epoch 的桑基/流线：红方流线急跳（空间易主），蓝方渐变（共享生长）—— 微观层的”改名换姓”实录，也是 P1 探针论最直观的演示。

动画总装：V1-V3-V9 三幕连播成 90 秒 mp4（战报片），随论文发布 —— 可视化即传播，园体对外第一支”军演纪录片”。

四 · 协议细则（承前册，增三条）

  1. checkpoint 纪律：每 epoch 末双军各存全量 lora 张量 + sha256 入 manifest（先 pin 后析，园律）；回收走队列，0 字节即作废重收（矩阵旧案之戒）。
  2. 同屏对齐：所有图共用同一 epoch 轴与同一配色（红 #D08B55 / 蓝 #2E8FA3，园账法定色），结构-功能两轴永不分离呈现（V1‖V9 双子图为默认视图）。
  3. 盲评条款：图成之后、判读之前，抹去红蓝标签随机打乱，由园笔与主人各自指认哪组是旅制 —— 指对率入报（人眼能否仅凭结构图认出课程，是 C40 的零成本第三方检验）。
