PREREG_PB15 · 序算法全贯（v3，主人再改制）：六种排序共查一个比较神谕

状态：候批候射。v1 为两两联赛 (42 跑)；主人 0923 改制为海选： 「首先全部表演才艺, 第一名落定, 其他人再争第二把交椅, 依次类推」—— 全案缩至 18 跑，且天生免疫循环优势。铁律：判据先冻。

0. 原理（海选版）

第 1 轮：7 个候选各领队一次——每队 = 该候选居首 + 其余 6 域固定随机尾序， 全员七域连训；冠军 = 全场最佳者，首位落定。 第 2 轮：余 6 候选争第二把交椅（已定冠军保持首位不动），6 跑； 依次类推 → 总跑数 7+6+5+4+3+2+1 = 28 → 尾序共享后 18 （每轮各候选一跑即可，第 k 轮 k−1 个前缀已定，只需换第 k 位）。 贪心合法性：本律的因果单元恰是”谁先占位”——第 k 轮所有跑共享同一前缀， 唯一变量是第 k 位入场者，轮内严格受控比较；跨轮不假装可比。 v1 的两两矩阵降为副产：每轮冠军对当轮其余候选即记一条 ≻ 边， 攒够后仍可查环（循环优势案保留为观察项，非阻塞项）。

1. 设计（弹药全部在册）

  • 空间集 = exp11 矩阵七臂 {spring, summer, code, legal, medical, mid, general} （语料内嵌件现成，0.5B 单臂 ≈ 1 分钟）；
  • 赛制 = 18 跑七域连训（每域 3 epoch 半预算；轮内只换第 k 位，前缀冻结）；
  • 探针 = 各域 held-out NLL + 重叠方向冲突角（在册几何仪）；
  • 全部塞进 4 个 kernel（每 kernel 约 11 场），双席位两小时毕。

2. 判据（先冻结）

  • J1（轮内可判）：每轮冠军须跨双 seed 复现（7 轮至少 6 轮复现）—— 否则序效应低于噪声，全案记 ✗；
  • J1b（冠军指标先冻）：轮内评分 = 全七域 held-out NLL 均值（主）
    • 重叠冲突角（并列破序用）；禁跑后换指标；
  • J2（副产矩阵查环）：轮内 ≻ 边攒成的部分序若可扩成全序 → 贪心 O* 与 全序一致（双保险）；若攒出环 → 记”循环优势”观察案（不阻塞主案—— 海选本身无需无环性，此即其优于两两联赛处）；
  • J3（贪心 vs 抽样）：海选序 O* 与 5 个随机排列对照训练， 预测 O* 平均 fresh-probe 不劣于任何抽样（贪心免 n! 的正当性检验）；
  • J4（剂量解耦复查）：每场顺带记 C43 影子 —— 若 D 符号随两域剂量比翻转 （等剂量时反向），则该场记”序不压剂量”例，汇总成 C42/C43 分界图。

3. 输出

  • 胜关系矩阵 7×7（有向图入档）+ 拓扑序 O* = 本园第一张”课程表定理”；
  • 报告 report_pb15.json（每 kernel 即吐 REPORT_LINE，日志即幸存者旧制）；
  • O* 若稳定 → 直接喂模块二课程设计与 P-B12 旅制臂的批内排布。

4. 失败条款

J1 败 → 序效应不存在，C42 降级候审；J2 有环 → “循环优势”另案（观察性）； J3 败 → 贪心失当，回 v1 两两联赛或更大抽样（费用另批）。

  • v2（主人改制）：海选逐位定席 18 跑，轮内受控、免疫环、更省。 主人原话：「应该是海选，首先全部表演才艺，第一名落定，其他人再争第二把交椅，依次类推」；

6. v3 正文：算法全贯 = 序之存在性的重言仪器

神谕 O(X,Y)：最小场次对决——仅两域 {X,Y} 各 3ep 连训两跑（X先/Y先）， 胜者=先入应占之位。一次查询=2 跑，但答案缓存终身复用。

六算法共查一谕：插入（最坏21查）· 冒泡（21查）· 归并（≤17）· 快排（≤19）· 堆排（≤20）· 锦标赛（v2 海选即此，贪心）。n=7 时不同查询 ≤ C(7,2)=21 对 → 全案封顶 42 跑，缓存后实耗 ~25 跑 ≈ 25 分钟（0.5B）—— 六套算法等于白送，因为它们在查同一批对子。

核心升级——一致度 C 成为新观测量： | 六序输出 | 判读 | |—|—| | 全同（C=1） | 支配关系是真全序：O* 存在且算法无关 —— C42 之最强证 | | 聚成几簇 | 偏序：可并行课程表（簇内无序, 簇间有序）—— 比全序更贴生态 | | 两两乱散 | 无传递性/噪声主导 —— C42 塌，回 J1 | 贪心(v2)与比较排序的分歧点 = 非传递性藏身之处，分歧本身发表。

J5（新增·先冻）：全同判据 C=1 须跨双 seed 复现；簇结构以 Kendall τ 矩阵呈现。 J3 改读：随机排列抽检仍留（5 跑），验”排序解”之终态确实优于乱序—— 算法一致只证关系存在，不自动证该关系优化终态，两事两账。

副产：全部已查对子 = v1 完整 7×7 胜矩阵（自动回收）；v2 海选=其中锦标赛一列。 三版一案，账不重花。

7. 裸体审计与三补丁（0923 · 主人问”接得住吗”后自查）

裸处一 · 功效不足 (n=7 太小, 单查噪声可翻符号) → 补丁 A｜校准门先行：正式开赛前先跑 1 对×双 seed×2 序 (4 跑) 做功率自测—— Δ 须 ≥ 3×seed 内噪声才放行全案; 不达标则升 1.5B 或加 epoch 重定标, 仪器未验先射, 才是真裸体。4 跑换一夜安心, 值。

裸处二 · 一致度 C 无零分布 → 补丁 B｜置换零：“六算法全同”须对随机序零假设报 p—— 6 个随机排列全同概率 ~1/5040 (≈2×10⁻⁴), 加 Kendall τ 矩阵与置信区间; J5 双 seed 复现条款保留。
