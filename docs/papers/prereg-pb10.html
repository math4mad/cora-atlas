PREREG_PB10 · 子空间消融 = LLM 界的基因敲除（四句律反向臂）

状态：候批候射（C41 四句律之账单；主人 0922 夜 “按你的安排做” 之授权内） 铁律：阈值先写后跑；跑后只记不改。

0. 命题与操作

四句律：添加结构获得功能（前向臂，C31/C35 在册）；失去结构破坏功能（本实验）。 操作化 = 推理时把已训 adapter 的中心化子空间从残差流里投影剔除：

  • 取 ΔW_r（某层 r=16 的 LoRA 增量），全局中心化后 SVD 得目标子空间 P（前 k 奇异向， k 取能量 90% 截断，k 值先冻：k = 使 Σσ²≥0.90·Σσ² 的最小 k）；
  • 推理时改道：h ← h − P Pᵀ (h − μ)（等价于 ΔW ← ΔW − P ΔW Pᵀ 作用于增量路径）；
  • 对照三臂：①随机正交基同维投影（sham ablation，控制”任意去维”效应）； ②他空间子空间投影（特异性对照）；③无消融原模型（基线）。

1. 判据（先冻结）

  • PB10-J1（定向崩塌）：目标空间探针组 NLL 升至 ≥ base-无adapter 水平的 80% 区间内（即”该项功能近似消失”），且 rank 分位跌回 base 分布中位 ±10 分位；
  • PB10-J2（表型特异性）：他空间探针组与对照② 的变化 |ΔNLL| ≤ 0.02 nats 且 rank 跌 ≤ 3 百分位；sham① 不达标（若 sham 也崩 → 去维效应非特异，判 ✗ 并记）；
  • PB10-J3（疤预测·锈刀签名）：消融后以该空间语料重训小 LoRA（同预算 1/4 步数）， 收敛至原水平所需步数 ≤ 无疤 naive base 的 1/2 —— 权重序列犹在，只被投影遮蔽， 故”再学快于初学”（对应湿界：残余序列的同源性时钟）。
  • 全过 = C41 反向臂首证；J1 过而 J2 败 = 耦合是全局的，A3/A4 让路改写； J1 败 = 四句律在权重界不成立，LEDGER 记 ✗ 不遮。
