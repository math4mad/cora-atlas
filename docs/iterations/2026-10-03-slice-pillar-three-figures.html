母本：ima 笔记《切片柱阵·三图提示词（ima Copilot 图库）》doc 7511883443609699（主人 + ima-Lola，今晨 04:22； 本地只读正本见 chora/lola/notes/2026-10-03-slice-pillar-three-prompts.md，sha 8f4dcbf2…）。 术语碑：「切片柱阵（对决柱林）Slice-Pillar Array」＋「切片轴律」——本页为其三个样本图。 铁律：图库出的是示意；精确版须 Python / Gosling 按真数据重画——下列三图皆精确版（真数据或明确标注之示意）。

视觉语法：纵向实体行（顶→底）＋ 共享横向切片轴 ＋ 立起方柱（柱高＝信号）。

图1 · 儿童语言发育柱阵（v02 · 补齐版）

五维：词汇量 · MLU · 词类多样性 · 句法复杂度 · 指代清晰度。

  • 词汇量 ＝ Wordbank 常模（English American，production 中位）：4 / 52 / 256 / 492 / —； 36 月超出 CDI 域（斜纹空心柱「CDI 止」）。
  • 其余四维 ＝ 本地 CHILDES Brown+Bernstein（CHI，%mor/%gra 直取）： 词类多样性早长后平；MLU / 句法复杂度总趋势向上有回落噪声；指代清晰度（有定标记率） 0 → 0.12 → 0.20 → 0.10 → 0.28（整体上升）。

数据：data/wordbank-norms-en.csv（带出处）。仅限研究·非商业。

图2 · 生物体 time-spine（生命尺度柱阵）

切片轴律之现场：同一批物种—— - A · 等距年龄轴（0–80 年线性）：果蝇/小鼠挤在原点，被压成一条线； - B · 生命阶段轴（卵/幼/亚成/成/老，各物种自归一）：跨尺度同框。

概念图·示意（lifespan 与里程碑取公开常识量级）。

图3 · 技术迭代柱阵（对决柱林）

  • 对决柱林：GPU 两行同为 FP32 TFLOPS，可比——AMD 早年（HD5870）曾压 NVIDIA， 2016 后 NVIDIA 反超并拉开（RTX 世代陡起）。
  • iPhone 行：相对性能指数，示消费电子节奏。

数据：data/tech-iteration.csv（近似取整·示意）。

三图与碑的榫

碑 三图所证
切片柱阵（对决柱林） 诸行共享一条切片轴、各自立柱——图1/图2/图3 皆此形；图3 显「对决」义
切片轴律 图2 以两轴并置现身说法：换轴即换故事
切片微元律（Δx 切片律） 柱即微元：每柱＝一个 Δx 片上的积分量；轴即分格
