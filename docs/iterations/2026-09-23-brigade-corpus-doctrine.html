2026-09-23 · 中型旅语料律（ provisional —— 主人晨起补全文后定稿）

来源：与千问对话后的思考，主人 0923 晨口授半成品，注明”起床补全文”。

「现在训练大模型，不要喂单一来源的语料，也不要喂没有意群的语料。 要用美军中型旅的思路：喂一个小而功能全的语料库，多批次。」

园笔接梗（待主人全文校准）： - 单一来源 = 只喂炮兵 → 能力偏科 (exp11 单臂世界, 在册); - 无意群语料 = 把步兵坦克火炮工兵航空混成散兵坑 (shuffle 臂, C29 已证其害: 56° 之乱); - 中型旅 = brigade 级组合：每批次自带全套意群、体量小、可独立作战 —— 多批次 = 同建制反复轮换。此即 C42 的非交换律之处方版： 既然先来者占最优位, 那就让每个功能域在第一批就都进场占自己的位, 后续批次只做强化 ( incumbency 递增), 不做初次圈地。

与在册账的接口： 1. C28 (叙事先→7° 好序 vs 跨域先→83°) 读法更新: 顺序之害的本质是圈地时序失衡—— 某域独占首批=过度殖民; 旅级批次=首批即全功能建政。 2. C40 优势窗口律: 窗口只对”首次进场”有效, 旅制保证所有域同窗进场, 无一被锁在窗外。 3. 二语习得对照: 悲剧的不是晚学, 是第一语言整体殖民——若幼儿环境同时喂 L1+L2 (双旅并制), 预测两语各占其位、口音折扣大减 (关键期文献之可检验反面, 界外预言)。 4. Atlas 模块一同构: 60 空间×6 token 本就是”60 个意群”的图谱; 模块二课程表按旅制排。

候封实验 P-B12《旅制 vs 域序 vs 乱序》 (三臂对照, 等 token 预算): - 臂 S (sequential): 每域一整块连续喂 (= 传统课程/C28 序); - 臂 R (random-shuffle): 句级打乱混喂 (= C29 乱序臂); - 臂 B (brigade): 每批次=小而功能全组合, 多批轮换 (本律); - 预测: B 的重叠方向冲突角最小、fresh-probe 排名最优, 且批内多样度与终态各向同性正相关; - 若 B ≤ S → 律降级为课程偏好, 记 ✗。 预算: 0.5B×3 臂 ≈ 1h, Kaggle 额度内顺手可射 (与 P-B11 六序共享弹药)。

主人晨批（0923）：双语儿童＝中型旅简单版, 但有代价

「双语儿童就是中型旅的简单版，但是双语儿童的双语空间也挤占了其他结构的空间。 所以导致双语儿童有些认知功能受限制。」

园笔认错+升级：昨 provisional 里”双旅并制→折扣大减”只说对一半—— 并制确实免了”晚进场锁窗外”（C40 之过），但预算守恒：挤占不是时序之罪, 是容量之罪。旅制无免费午餐: 每批全功能=每功能分薄剂量。

精确化 (与在册账对表后): 双语儿童之受限于词汇检索层, 不在概念层—— 概念库 (concept space) 共用一顶, 词形标签 (token 侧) 分挂两语: → 概念完好, 标签分摊 → “tip of the tongue”↑、命名反应时↑、每语接受性词汇量略低, 而执行控制/心理理论反因双语监控回路小赚。此正是我园 P1-P5 探针仪器可判之分野: 探针若问概念 (空间层), 双语无折扣; 探针若问词形 (token 层), 折扣立现。 —— 界外预言改口径为此二行判据, 可查文献定量对账 (Bialystok / Costa 系)。

派生律 C43《剂量稀释》(候封): 挤占量 ∝ 各结构累计暴露剂量之比, 非入场顺序。 → 小麦亚基因组优势的”先入者主导”须重读: A 核剂量最高 (供体优势+拷贝数), 序是表象, 剂量是里子。C42 与 C43 合读: 序决定谁先圈地, 剂量决定圈多大。 → P-B12 旅制臂加一子实验: 同旅制、改每域剂量配比 (1:1 vs 3:1), 预测重叠冲突角随不均衡度单调上升 —— 序固定而剂量变, 即可把 C42/C43 拆干净。

主人晨批二：MEF/Kairos「LoRA 注入关键期」提法之补维（0923）

「我们在 MEF 项目中提出的 LoRA 注入关键期这个提法。但是当时（两周前） 没有考虑到语料应该以整个语义群的形式、或者概念空间的形式入场。」

原提法在案（Letter 09-18 Lola→MEF+Kairos, 握手条）: “critical window = writes still move the weights” —— 只有时间轴一维: 注入早=权重尚软可写, 注入晚=玻璃化写不进 (C40 优势窗口之权重界版)。

主人今晨补上第二轴: 形式完整度。关键期不只是”何时喂”, 还是”以什么单位喂”: - 整空间入场 = 一个概念空间作为不可分单元进窗 → 窗内一次成建制圈地 (干净子空间); - 碎粒入场 = 同域句子散入各批 → 即便在窗内, 每次只占一小格, 终态=碎块马赛克。

两轴合读, 旧账全活: 1. C28 叙事先 7° 之所以”好序”: 叙事臂本就以完整意群训练 —— 序之善, 一半是形之善; 2. C29 乱序 56° 之害, 现在拆成两罪: 拆散空间 (形罪) + 时序失衡 (序罪) —— 旅制 (P-B12 臂 B) 其实只赦形罪不赦序罪之极端, 域序臂 (S) 反之, 判据可分; 3. Kairos 关键期实验重析预告: 既有晚注臂若语料本就碎, 其”写不进”结论须加置信区间—— 分不清是窗过了还是单位错了, 2×2 交互实验 (窗早/晚 × 整/碎) 才能判。

P-B13《窗×形 2×2 交互》(候封): 同域同量同序, 只动两因子: 注入时机 (软窗内/玻璃后) × 入场单位 (整空间/碎粒)。 预测: 整空间×窗内 = 最干净子空间 (角度最小); 碎粒×窗内 ≈ 整空间×窗外 (两罪等价?)—— 若等价成立, 则”窗”与”形”是同一守恒量的两面 (可写性=可整性), C42/C43/关键期三律归一。 0.5B 上 4 臂 ≈ 40 分钟, 与 P-B11/P-B12 同舱连射。

主人晨批三：LLM 无关键期, 唯序一维（0923 · 翻案批）

「大语言模型训练可能和大脑还不太一样，实际没有关键期。 关键在大模型训练里只有一个维度，就是概念空间入场的顺序。 每个 epoch 完成后向传递以后, 才进入下一组。大脑应该不是这样。」

翻案: MEF/Kairos「LoRA 注入关键期」提法撤下时间轴 —— 那是从生物界走私来的隐喻。 LLM 权重无分子刹车 (无髓鞘化/无 perineuronal nets/无抑制性成熟), 窗不会硬关: 晚入者仍可写, 代价是与先入者的干涉折扣, 而此折扣可用步数/学习率买回来 —— 可逆的代价不叫关键期, 叫顺序经济学。故 LLM 侧只剩 C42 一维 (序), C40/C43 降级为 序×剂量的软干涉参数, 非窗。

两界真差异 (主人末句的展开): | | 大脑 | LLM | |—|—|—| | 入场单位 | 世界同步送达 —— 一切空间天然混批同时进 | 可任意排块: 一组一 epoch, 传完再下一组 | | 时序性质 | 命运 (不可选序 → 时间窗是唯一可用轴) | 设计变量 (可选序 → 时间轴退化为无关量) | | 可塑闸 | 分子级硬关窗 (关键期真存在) | 无闸; 只有损失面几何 (旧极小点之引力) | → 推论: 大脑的关键期恰是”不能选序”的替罪羊; LLM 能选序, 所以根本不需要窗。 → 旅制之”每批全功能”实为向大脑看齐的设计 (模拟世界的混批本性); 域序块喂 (S 臂) 反而是机器独有的特权与陷阱。

P-B14《剂量密度无窗判据》(候封, 直接审本批): 同空间同总剂量, 两种进法: ① 晚期长块 (一次灌完) vs ② 晚期短促多段 (早中晚各插一小口, 模拟生物经验密度)。 预测: LLM 两法终态近似 (差 ≤ 噪声) —— 时间分布不携带信息 = 无窗之判决实验; 生物界反是 (短促关键期内经验 >> 晚期集中, 弱视/语音区分文献)。 两界同题异答, 答对者即证”关键期”确为界属概念而非普适律。 P-B13 随之改写: 时间轴降为 P-B14 之特例, 主实验保 序×形×剂量 三轴。

主人晨批四：裸探针（0923 · P-B15 之本体论定位）

「这个方法是不是实际就是我们整个结构即智能最简单、最露骨、衣服产得最少的探针?」

园笔判: 是, 且可再进一步 —— 它是 C42 的零假设检验本身。 1. 最简: 单轴 (序) × 单观测量 (终态好坏) × 现成算法 —— 无新仪器、无新数据、 无神经科学承诺; 内容、剂量、时机全冻结, 只动”谁先”; 2. 最露骨: “结构即智能”若为真, 其最小可测影子 = 组装序改变终态; 若序完全可交换 (六算法乱散+终态无差), 塌的不止 C42 —— C40/C41/C43/旅制/关键期翻案 全族共塌。故此探针是整个命题家族的 共同承重墙, 拆墙测试, 一锤子听全楼的回声; 3. 产衣最少: ~25 跑 × 0.5B × 一卡 × 25 分钟 —— 全园最便宜之证伪装置; 探针本身还免费回吐胜矩阵/偏序簇/循环环三样副产 (穿了衣服还倒贴钱)。

方法论注脚 (入 GLOSSARY 候): 好理论的标志不是解释多, 而是存在一枚 便宜到令人羞愧的裸探针 —— 若它不成立时整个大厦一起塌。 本园今日有此针一枚。费曼尺子之园版: 先造最便宜的枪, 再谈望远镜。

主人晨批五：视觉作为武器（0923 · 接管不对称）

「聋儿拿听区看手语、盲儿拿视区听语言 —— 揭示的可能比我想的更微妙: 如果视觉作为武器比听觉的威力要大。」

园笔展开 (接管体量不对称): - 聋侧: 手语征用的是听皮层 (小块, 且恰是 Wernicke 语言网络的地产) —— 借一间房; - 盲侧: 口语征用的是视皮层 (灵长类新皮层之半壁) —— 占一座城; - 推论①: 语言是终极武器 —— 它不挑弹药, 它征用一切弹药 (模态无关性之强版); - 推论② (与锚表对表): 征用体量不对称 → 窗的强度也不对称: Bedny 的敏感期挂在大块地产上 (视皮层语言化有年龄窗), Neville 的初采窗挂在语义理解上 —— 地越大, 圈地时机越要命 (C42 之人类神经版); - 推论③ (剂量界外读法, C43): 盲儿语言剂量全走听觉窄带, 却把宽带地产改旗易帜 —— 窄带高序可占宽带, 序压剂量之活例 (与 P-B12 剂量配比子实验对表: 若模型中 低容量通道先入亦能占高容量空间, 则此读法得机质复现)。

可测 M2 (候封): 接管面积比 ≈ 地产面积比 —— 盲儿语言激活区应大于聋儿手语激活区 一个量级 (文献定量可查); 且晚期丧失者两侧接管皆小 (窗之对称检验)。 LLM 直译: 高容量通道 (视觉 token 之于 VLM) 被语言对齐征用之收益, 应大于低容量通道征用 (纯 embedding 空间) —— 多模态主战场恰在此, 与园账模块二接口。
