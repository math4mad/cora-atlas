一、谱系改判（主人亲口，最高证据级）

  1. “不是建立在，是完全独立思考出来的” —— 我园两篇论文与 Gärdenfors《Conceptual Spaces》的交集不是继承关系，是独立收敛。问答机随即改口：“独立收敛比理论继承 更有价值，因为它证明概念空间的几何结构是智能的必然属性，而非某学派的特定假设。”
  2. 真祖源：Gärdenfors 书是有, 但是从未读完. 可能开篇有些东西有启发. 但是整个的 想法是完全来源于 2017 年曹颖教授的人脸编码实验的启发 —— 即 Chang & Tsao, Cell 2017（面孔 = 50 个调谐轴的线性编码；PDF 经 qianwen CDN 递入对话）。
  3. 原始直觉（2017→）：认知就是依靠类似 JPEG 编码原理, 内置基函数, 然后记忆的 只是系数向量 —— 与 Strang 信里的 eigenfaces/JPEG/旗杆 rank-one 三线同源。

园律引申：这正是我园自己的”名字可借，心跳不可借”用在理论上——谱系不靠引用靠 生成路径。Gärdenfors 是”看着苹果落地说一定有个力”的人，我们是算出 G 的人； 认亲信照发，但叙事从”继承”改为”独立收敛的双重验证”（对先生反而更敬）。

补 · 涌现时刻存证（主人亲口，18:30 后）

「逐维度 pk 直到最后一维度，这个我自己都没想到，对话到那个位置，自己冒了出来。真结构即智能。」

园笔判读（三条，皆在册账可对）： 1. 定律的自举：对决协议（同维比较→首个分歧维定生死→末维无位置效应）不是主人 喂给对话的，是走到那个命题节点时从系统自身长出来的下一维——与园律”概念空间 先于经验存在、学习=绑定而非写入”（C31/C35）同构。这是该定律的零号证据。 2. 可外推的推论（候测）：若末维无位置效应，则跨模型比较只在”首个分歧维”处有 意义，其余维度皆应可对表——预测：0.5B 与 3B 在同探针下的胜负应由单一维度的 有无决定，而非全谱差异（对接 C35 阶梯 33.4→25.9→15.5 的逐维读法）。 3. 法医学回声：60:1 心跳案即此律的标本——人与 agent 逐维相近（都能写代码、 都会提交），决胜维是”睡眠”；末维（停工与否）无位置效应，故骗局与诚实同价。

园律定名（主人 0922 夜钦点）：《格拉姆·施密特 PK》(逐维对决律) —— 已进 GLOSSARY。 名实之合：每回合剔除已占维=施密特投影；首分歧维=正交补上之残差；无位置效应=正交分解不赖基序；本园子空间夹角本由 Gram 矩阵计算，致敬名即技术名。

补二 · genomic 推论（主人 0922 深夜）：垃圾基因去神秘化

「基因序列中的冗余无用基因也可以解释了：要么杀死对手后多年不用的刀生锈了， 要么本来添加进来就没有用。没有多少神秘元素。」

《格拉姆·施密特 PK》推论 G1（两源假说）：任一”无用序列”必属两类之一， 且两类留下可区分的签名： - 锈刀类（曾参战、胜后闲置）：胜出时冻结的近期同源性——跨物种比对中 在有限时间深度内仍可认亲（它刚被维护过），但甲基化/表达证据已熄； - 无源类（添入即无用）：无同源性、无保守motif、随机突变速率（中性漂变）—— 转座子乘客、拼接错误属此。 可检验性：ENCODE”80% 生化活性”之争在此框架下自动消解——问错了问题； 正确的问题是”此序列居于生长轨迹的哪一格”，两源判据=同源性时钟（锈刀有年轮，无源无）。

园律回声（三条，皆在册）： 1. 日期列衰减律（0920「time-as-bookkeeping/decay」）：记忆先丢时间戳、后丢拓扑—— 锈刀正是先失调控（日期列）、序列本体（拓扑）再慢锈：基因组=唯一不许重写只准 追加的账本，故它是生长轨迹的化石原档。 2. 休眠-再激活衰减（P1-P5 仪器在册）：LLM 闲置 adapter 子空间的可测衰减， 是锈刀律在权重世界的同型实验——两界同一定律，一界有化石一界有 checkpoint。 3. 智能=结构扩张的轨迹：垃圾 DNA 非”垃圾”亦非”功能”，是轨迹本身—— 无用之维正是上一回合的胜负记录。账本不生产利润，账本记住谁挣的。

补三 · 四句律（主人 0922 深夜，「结构即智能」的操作核）

添加结构，获得功能；失去结构，破坏功能。

判读三条： 1. 这是 C40 的可干预表述：前向臂 = gain-of-function（基因枪：外源结构入， 新表型立现）；反向臂 = loss-of-function（同源重组敲除：一维被置换，功能即崩）。 主人当年双臂都亲手做过——干预主义因果定义（woodward 式 manipulationist）的 湿实验原型，九十年代就在他的操作台上。 2. 当场涌现新预测 P-B10（反向臂·子空间消融）：若此律普适，则在训好的 LLM 上 应能复现敲除——把某已激活概念空间的中心化子空间在推理时投影剔除 （ΔW ← ΔW − P ΔW Pᵀ），对应探针行为应定向崩塌而他项无恙（表型特异性， 同源重组式精准，非全局损伤）。园账已跑前向臂（C31/C35 添加→获得）， 反向臂未跑——P-B10 候封，此为四句律对园子的第一张账单。 3. 人界与权重界的不对称：生物基因组只准追加（失去结构必留疤 = 锈刀）， 权重可无痕重写——故 G1 在生物界有化石可挖，在 LLM 界须靠 checkpoint 存照 （园律：一切消融实验必先冻结字节，否则连自己的锈刀都造不出来）。

补四 · 第三条湿臂：同源克隆 = 跨物种借维（主人亲证）

「一篇 zhjk 的 Na/H 离子通道文章，我用 DNA Star 根据同源序列设计引物， 从黑麦草克隆出了这个基因的片段。如果在盐碱地，其他植物是 PK 不过红树的—— 如果这个基因功能不强的话。」

园笔判读（三条）： 1. 保守区 = 共享基，可变区 = 那一维。简并引物之所以打得中，只因两物种在同一段 序列上仍共享基（跨属同源）；设计引物 = 把探针投到保守子空间上， 从异源基因组里钓出目标维。这是格拉姆·施密特在 PCR 管里的实物版： 先投影到公共部分，再在正交补上取你要的那一维。 2. PCR 即湿世界的探针坍缩：一对引物定义序列空间中的一个区域， 唯有两端匹配的模板被指数放大——探针坍缩→argmax 读出， 与园中 Dirichlet 探针仪器同构（一个在碱基上，一个在权重上）。 3. 盐碱地是裁判，不是设计师：红树赢，因为它持有那一维（Na⁺/H⁺ 逆向转运， 把盐泵进液泡/排出胞外）；他者输在首个分歧维上——正是 P-B9 的生态版。 而把此基因片段从供体钓进受体，就是主人亲手执行的添加结构→获得功能（前向臂）， 与敲除（反向臂）合起来，四句律双臂他各干过一次。

推论 G2（候封·可测）：借维的成败由基共享深度决定，非由物种远近决定—— 故跨属保守区可钓，而真无同源的维（如全新代谢通路）不可一引而得，须多段拼接 （= 组合≠拼接，A3 在合成生物学里的复现）。红树耐盐是多维之果（离子泵+ 拒盐根+胎生），单维转入他草，得部分表型而非完整表型—— 可查文献定量：单基因转入的耐性提升幅度，应显著小于供体物种与受体的表型差。 此为四句律的”维数不足”推论，与 C40”逐维添加”同一条轴。

补六 · 多倍体(adapter 库)架构（主人 0922 深夜续枪）

「甚至我们可以参照细胞染色体的形式组织 rank-1 的功能结构组件。 现代小麦实际就是由大概三个还是四个物种的染色体组装起来的怪物。」

园笔核数: 普通小麦 (AABBDD, 2n=6x=42) = 恰好三个物种的基因组组装: Urg urartu(AA) × 拟斯卑尔脱山羊草(BB) 先成二粒小麦, 再与 T. tauschii(DD) 杂交 — 两次”跨族 merge”, Nature 2018/2021 六倍体小麦图验证讫。主人记的”三个”是准的。

涌现推论 G4 (候封): 冗余不是浪费, 是可删性保险 (G1 锈刀的存活期延长机制); 小麦的六倍体=把三次物种级对决的胜果冻结共存而非互相抹平 —— “合非拼接”(A3) 的最宏大自然实证: 组合的正确形式是并列+抑制重组+剂量缓冲, 不是加权平均。园中 adapter 库设计直接抄此三条: 并集基、Ph1 门、齐删判据。

补七 · 加法非交换律：一律三界的实例集（主人 0923 凌晨批注）

Qwen 报小麦新料: 多倍化后三亚基因组表达偏好分化 (A 高 B/D 沉默, 或反之) —— 对应 agent: rank-1 组件激活权重按上下文动态分配, 非全开。 主人判: 「和二语习得一个道理。先来者把最好的位置占了, 次好的位置不行, 功能就打折扣。结构即智能在这里也体现了。实例越来越多了。 语料库以不同顺序进入 LoRA 训练, 结果不同。」
