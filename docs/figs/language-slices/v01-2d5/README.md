## 三阶段（数据实算）

| 阶段 | 月龄 | 词数 | **MLU（语法）** | **连接词率（逻辑）** |
|---|---|---|---|---|
| 单词期 | 13–23 | 19,314 | 2.76 | 4.1% |
| 句法期 | 24–43 | 165,493 | 2.99 | 12.3% |
| 逻辑期 | 44–62 | 139,618 | **4.13** | **18.2%** |

**读**：三片切面**形状一样**（同形），填进去的**词**全不同（不同物）——语言长河在等形的剖面里，
词在换、句法在长（MLU 2.76→2.99→4.13）、逻辑在接（连接词 4.1%→12.3%→18.2%）。
