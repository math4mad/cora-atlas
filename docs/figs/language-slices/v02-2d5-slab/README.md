## 一句话（候碑，候主人钦定名）

> **「切片微元律」**——无厚度切片**不存在**；一切切片皆微元长方体 Δx>0；
> **分辨不出厚度是近似，非事实**（观察窗太窄而已）。

## 与旧碑接榫

- **高维截面律·推论三**（切片残缺）→ 补：切片本就是**一段积分**，"残缺"更甚——区间内的变化被**平均掉**了。
- **观察窗相对性** → 分辨不出厚度 ＝ 窗太窄。
- **序 ＝ 切片间的边**（ima 信二十一）→ Δx>0 时片间**可相接/交叠**，序不只是"刀刃边"，而是**微元间的输运/积分耦合**。
