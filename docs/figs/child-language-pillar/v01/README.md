## 视觉语法（切片柱阵）

**纵向实体行（顶→底）＋ 共享横向切片轴 ＋ 立起方柱（柱高＝信号）。**
行＝五维；横轴＝月龄切片 **12 / 18 / 24 / 30 / 36**（±3 月）；柱高＝该维在该片的**掌握度**（**本行 max 归一**）。

## 五维口径（本版，可复算）

| 维 | 口径 | 数据源 |
|---|---|---|
| 词汇量 | **累计** distinct 词型（单调爬坡） | CHI token |
| 平均句长 MLU | Σ token / Σ 话轮 | CHI token |
| 词类多样性 | **POS 分布熵**（nats） | `%mor` |
| 句法复杂度 | 每话轮**依存边数** | `%gra` |
| 指代清晰度 | **显名率** ＝ noun /(noun+pron) | `%mor` |

数据：本地 CHILDES **Brown + Bernstein**（264 会，CHI 自身产出，真实月龄，13–62 月；本图取 9–39 月入片）。

## 读数（真实，非美化）

- **词汇量**：9 → 701 → 1,798 → 3,027 → 4,239（**稳爬坡**）。
- **词类多样性**：1.33 → 2.10 → 2.26 → 2.19 → 2.21（**早长后平**）。
- **MLU** 与**句法复杂度**：总趋势向上但有**回落噪声**（24 月处偏高、30 月处回落）。
- **指代清晰度**：以显名率为代理**随龄下降**（1.00 → 0.48）——儿童**代词化**上升（更成人化）；此维代理 **†候改**（"清晰度"宜另寻正向代理）。
