> 词汇量 · MLU · 词类多样性 · 句法复杂度 · 指代清晰度——用
> **方案一：大小不同的圆**；**方案二：45° 视角的三维柱状图**。

## 两案（同数据 · 同长轴）

- **方案一**：每片五指标＝**大小不同的圆**（面积 ∝ 值，居中排 3+2）。
- **方案二**：每片＝**45° 三维柱状图**（五指标一排，高矮不同，带地板与退向）。
- 长轴＝**时间（月龄 12 → 42）**；各指标**自身 max 归一到同一高度域**。
