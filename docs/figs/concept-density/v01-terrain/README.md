| 要素 | 取法 |

| **地** | 一副公共义素基，取两条**带符号的义素轴**作平面（正极义素 − 负极义素，箭头指向正极）|

## v01 的读数（三事）

1. **三摊抱团**：在「室内→室外 × 固定货架→流动摊车」上，三摊云心落在 (+0.75…+1.00, +0.44…+1.00)，
   挤成一坨——它们是「路边摊」同一族的三个变体，**共用同一副义素基**。这正是「不并排」要让人看见的事。
2. **塑胶凳悬在中间**：落 (+0.20, −0.11)，在引擎真球 超市(−1,−1) 与三摊(约 +0.8,+0.7) 之间，
   略偏三摊侧——与观察台账（`website/observations.json`：路边摊后验 0.715、超市 0.267）同向。
3. **轴变化**：换轴对，塑胶凳的坐标显著移动
   ——(室内→室外 × 固定货架→流动摊车) (+0.20,−0.11) ／ (固定货架→流动摊车 × 正式→喧闹) (−0.11,−0.06)
   ／ (预包装→现做 × 正式→随意) (+0.00,+0.76)。
   **一个词在世界模型里的位置不是绝对量，是相对所选义素轴而言的**——今日「轴变化」之所得。
