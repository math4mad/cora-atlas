# 儿童发展 · 切片柱阵 · 概念演示海报（v01）

> **主人 1003 定调**：要「**A 圆 / B 三维柱**」的整体观感/海报感；
> **这是概念演示——主要演示「变化」与「轴趋势」，不为展示精确数据。**

## 本版做了什么

| 取舍 | 说明 |
|---|---|
| **去数字** | A 圆、B 柱**一律不标数值**（精确读数另有 A–F 对照集 / 热力矩阵 D 承担） |
| **放大形** | 圆更大、柱更高，版面留白 → 观感优先 |
| **趋势线** | A 片沿「词汇量」槽位一条淡虚线贯穿月龄 → **成长指引** |
| **长轴＝时间** | 月龄 12 → 42，带方向箭头；每片＝该月横截面 |
| **用途声明** | 页脚明写「概念演示，只示变化与趋势，不作精确读数」 |

## 两个方案

- **A · 圆簇**：五指标＝**大小不同的圆**（面积 ∝ 值），看**生长与趋势**。
- **B · 45° 三维柱**：五指标＝**高低不同的柱**（有退向/纵深感），看**形与势**。

## 诚实条款

- 数据：本地 CHILDES（`%mor`/`%gra`），只作**形状/高低**，各指标自身 max 归一；**不作精确读数**。
- 与 `child-dev-slices`（圆+柱双面板）、`child-dev-variants`（A–F 六式对照）并存，**互不覆盖**。
