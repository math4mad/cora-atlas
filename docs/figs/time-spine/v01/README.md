# 生物体 time-spine · 生命尺度柱阵（切片柱阵 · 图2）（v01）

> **母本**：ima 笔记《切片柱阵·三图提示词》`doc 7511883443609699`。
> 笔记云：图2 目的是「先把**跨尺度 lifespan 怎么同框**讲清楚，是**切片轴律**的现场教学」；
> 并警告「**勿用等距年龄轴**，否则昆虫被压成一条线、大象溢出」。

## 本图把这一课做正：同一批物种，两种切片轴并置

| 面板 | 切片轴 | 效果 |
|---|---|---|
| **A** | **等距年龄轴**（0–80 年 线性） | 果蝇/小鼠挤在原点——**被压成一条线** |
| **B** | **生命阶段轴**（卵/幼/亚成/成/老，各物种自归一） | 各尺度**同框可比** |

**两句同读**：同样的数据，换一条切片轴，柱阵讲的故事就换了主角——**切片轴律**。
柱高＝该阶段**体型/代谢/里程碑强度**（示意）；色＝物种。

## 诚实条款

- **概念图·示意**：lifespan 与里程碑取公开常识量级（果蝇 ~55 天 / 小鼠 ~3 年 / 龟 ~数十载 / 人 ~80 / 象 ~65），
  **非精确数据**；若要精确版须逐物种取文献值。
